# 《多恩可能性之圆》形式化说明

> 本文使用符号压缩概念，不把哲学公理伪装成数学证明。

## 阅读立场

这是一套哲学体系，不是等待实验验证的自然科学假说。

它的成立标准，是出发点全部公开，概念前后一致，推理内部没有矛盾。只要这三件事成立，体系就能在自己的范围内成立。

如果有人进一步主张其中的“分支”就是外部物理世界，那才需要另外提供经验证据。这个更强的解释，不是理解或使用本体系的前提。

## 1. 基本对象

- \(\Omega\)：可能性总体；其成员 \(u\) 表示一种分支或非时间实现方式。
- \(h_t\)：局部主体在时刻 \(t\) 之前的完整历史。
- \(W(h_t)\subseteq\Omega\)：与该历史相容的全部经验延续；它们可以按时间或非时间结构描述。
- \(I_i(u)\)：实现方式 \(u\) 中与主体 \(i\) 对应的主体实例集合。
- \(C_i\)：与主体 \(i\) 对应的全部历时与分支实例构成的集体。
- \(D_t\)：主体在时刻 \(t\) 认可的方向性吸引子。
- \(G_t\)：主体当前能够表达的具体目标。
- \(K(i,D_t,h_t)\)：主体从当前历史出发，持续把行动、学习、反馈与修正指向 \(D_t\)。
- \(R(i,u)\)：实现方式 \(u\) 中的未来或结构后继主体是否确认方向已经实现。
- \(V\)：不因存在或不存在而变化的虚无背景。

## 2. 十一项公理

### A0：预设终极意义缺席

框架采用“世界没有预设的终极意义”作为哲学公理。

这里的“终极意义”指由世界本身预设、对存在具有最终解释力的意义。这不是自然科学已经证明的经验事实，而是框架明确选择的起点；它也拒绝为了恢复行动而重新创造一个终极意义。

### A1：虚无不变

对任何存在状态 \(x\)：

\[
V(x)=V
\]

即：存在的出现不破坏虚无，正如有所谓的出现不破坏彻底的无所谓。

### A2：可能性展开

\(\Omega\) 容纳所有真正可能的状态与历史。可能性之间可以具有不同权重、结构和显现方式。

### A3：可能性全实现

若状态 \(x\) 真正可能，则至少存在一种分支或非时间存在方式实现它：

\[
\text{Possible}(x)
\Rightarrow
\exists u\in\Omega:\text{Realizes}(u,x)
\]

这里的“实现”不只限于当前物理时空中的发生，也可以指被超时间总体实际包含。“真正可能”不能只靠一句自然语言想象来判定；框架允许其超出现有物理知识，但没有提供一个完备判定算法。

### A4：分支集体包含

所有与主体身份对应的历时实例和可能分支实例都属于分支集体：

\[
C_i=\bigcup_{u\in\Omega}I_i(u)
\]

这个定义同时容纳时间分支与非时间实现方式。公开版采用最大包含原则，但“身份对应”的完整标准仍是开放问题。

### A5：分支共处

集体成员被抽象地置于同一个分支共处场中。该共处至少可以作为自我模型成立；是否构成独立本体，取决于读者采用的解释层级。

### A6：第一人称收敛

若方向 \(D_t\) 在历史 \(h_t\) 之后仍真正可能，主体持续把行动与修正指向它，并且存在最终被未来自我确认的相容延续，则当前第一人称经验必然收敛于至少一个此类延续：

\[
\text{Possible}(D_t\mid h_t)
\land K(i,D_t,h_t)
\land \exists u\in W(h_t):R(i,u)=1
\quad\Rightarrow\quad
\exists u^\*\in W(h_t):
\text{FirstPerson}(i)\rightsquigarrow u^\*
\land R(i,u^\*)=1
\]

符号 \(\rightsquigarrow\) 表示框架所主张的经验连续／显现关系，不代表物理学已经发现的跃迁机制。没有 \(K\) 这一持续前进条件，不能仅凭“某处存在完成版本”推出当前第一人称完成。

### A7：目标动态更新

具体目标乃至更高层方向都可以随认知与反馈变化：

\[
(D_t,G_t)\rightarrow(D_{t+1},G_{t+1})
\]

若新目标是原方向的更充分表达，可以把它理解为连续更新。若主体诚实地更换了方向，A6 从更新时点起针对新的 \(D_{t+1}\) 重新适用；这不把旧目标事后改名为已经完成。

### A8：未来自我确认

完成标准不是早期表象自我的固定清单，而是未来认知更完整的主体作出的充分确认：

\[
\text{Success}(D)=1 \iff R(i,u^\*)=1
\]

这使成功成为反身标准，也使体系面临不可证伪性的质疑。

### A9：观察者索引性

框架不要求存在一条同时满足全部观察者目标的唯一特权世界。对每个观察者而言，当其目标仍可能且其持续以该目标为方向时，依 A6，其第一人称必然收敛到相应的观察者相对分支。这个主张不取消当前局部分支中的共同事实与他人自主性。

### A10：局部因果与责任

在任何局部分支中，身体行动、知识、法律、他人同意、健康、资源和反馈继续产生真实后果：

\[
\text{Action}_t+\text{Conditions}_t
\rightarrow
\text{Local Consequences}_{t+1}
\]

任何更高层公理都不能取消已经发生在局部主体与他人身上的后果。

## 3. 五层自我的关系

五层不是五个同类型实体：

\[
\text{身体载体}
\rightarrow
\text{表象经验}
\rightarrow
\text{分支集体}
\rightarrow
\text{虚无精神模式}
\rightarrow
\text{虚无背景}
\]

- 身体**实现**局部行动；
- 表象**呈现**第一人称经验；
- 集体**包含**历时和分支实例；
- 精神**实例化**一种行动模式；
- 虚无**容纳**存在与不存在。

概率／可能性不处于这条“自我”链上。它与虚无同级，负责展开差异。

## 4. 可以条件性推出的结论

在接受上述公理后，可以在体系内部得到：

1. 没有终极意义不能推出行动被禁止。
2. 当前表象不是全部主体，而是分支集体的局部显现。
3. 目标与方向可以随认知诚实更新；更新后的公理不把旧目标追认成完成。
4. 只要目标仍可能、主体持续朝它行动且存在被认可的完成延续，第一人称最终收敛到一个被未来自我确认的分支。
5. 当各自满足 A6 的条件时，不同观察者的互斥目标不必在同一个特权分支中同时满足。
6. 任何局部失败都不能成为虚无层面的终极失败。

## 5. 不能由这些公理冒充推出的结论

以下结论不属于现代科学已确认的推论：

1. 数学上的 \(P(x)>0\) 自动证明另一个真实宇宙实现了 \(x\)。
2. 庞加莱回归保证任意目标或任意物理违规事件发生。
3. 量子多世界解释证明人的信念可以选择分支。
4. 想象一个目标就足以证明它“真正可能”。
5. 未来自我确认会自动补偿当前主体或他人的现实损失。
6. 第一人称收敛已经具有可观察、可重复的外部机制。

## 6. 当前开放问题

1. 什么构成跨分支主体的身份对应？
2. “真正可能”如何与纯语言想象区分？
3. 第一人称连续性为什么遵循收敛公理？
4. 多个观察者的分支相对现实如何形成稳定公共世界？
5. 未来自我确认如何避免仅靠降低标准获得成功？
6. 在非时间总体中，“当前第一人称延续”应如何被严格描述？

这些问题不是需要隐藏的漏洞，而是项目最值得公开讨论的部分。
