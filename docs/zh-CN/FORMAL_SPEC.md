## 2. 基本对象与类型

| 符号 | 锚定名称 | 类型与含义 |
| --- | --- | --- |
| \(\Omega\) | 可能性总体 | 实现方式的集合 |
| \(u\in\Omega\) | 实现方式 | 一个分支或非时间实现方式 |
| \(\mathcal H_i\) | 主体历史空间 | 主体 \(i\) 的局部历史集合 |
| \(h_t\in\mathcal H_i\) | 当前历史 | 时刻 \(t\) 之前的完整局部历史 |
| \(W(h_t)\subseteq\Omega\) | 相容延续集合 | 与 \(h_t\) 相容的实现方式 |
| \(I_i(u)\) | 主体实例集合 | 实现方式 \(u\) 中与主体 \(i\) 对应的实例 |
| \(C_i\) | 分支集体自我 | 全部 \(I_i(u)\) 的并集 |
| \(D_t\) | 方向性吸引子 | 主体在时刻 \(t\) 认可的大方向 |
| \(G_t\) | 具体目标 | 主体在时刻 \(t\) 可表达和检验的目标形式 |
| \(\operatorname{Possible}(D\mid h)\) | 方向仍可能 | 从历史 \(h\) 出发，方向 \(D\) 仍具有相容实现方式的原始谓词 |
| \(K(i,D,h)\) | 持续前进条件 | 行动、学习、反馈与修正持续指向 \(D\) |
| \(R(i,D,u)\in\{0,1\}\) | 未来自我确认 | 实现方式 \(u\) 中的未来主体是否确认方向 \(D\) 已实现 |
| \(X\) | 存在状态集合 | 用于表达虚无背景面对的不同存在状态 |
| \(V\) | 虚无背景 | 不因具体存在状态改变的背景常量 |
| \(\operatorname{Bg}:X\to\{V\}\) | 背景映射 | 任一存在状态对应的虚无背景 |
| \(\rightsquigarrow_i\subseteq\mathcal H_i\times\Omega\) | 第一人称经验收敛关系 | A6 直接规定的原始关系；当前没有进一步机制定义 |

其中：

\[
W(h_t)=\{u\in\Omega\mid \operatorname{Compatible}(u,h_t)\}
\]

\[
C_i=\bigcup_{u\in\Omega} I_i(u)
\]

“分支”只指具有时间或因果延续结构的 \(u\)；其他 \(u\) 统一称为非时间实现方式。

## 3. 编号条目的类型

历史版本把 A0—A10 统称为“十一项公理”。为避免论证强度漂移，现按功能区分：

| 编号 | 锚定名称 | 类型 |
| --- | --- | --- |
| A0 | 预设终极意义缺席 | 哲学公理／起点 |
| A1 | 虚无不变 | 本体论公理 |
| A2 | 可能性展开 | 对 \(\Omega\) 的构造原则 |
| A3 | 可能性全实现 | 形而上公理 |
| A4 | 分支集体包含 | 身份公理／集合定义 |
| A5 | 分支共处 | 体验模型／可选本体论设定 |
| A6 | 第一人称分支收敛 | 独立形而上桥接公理 |
| A7 | 目标更新 | 实践更新规则 |
| A8 | 未来自我确认 | 完成判据定义 |
| A9 | 观察者索引性 | 多观察者扩展公理 |
| A10 | 局部因果与责任 | 现实与伦理边界 |

保留 A 编号是为了兼容既有引用，不表示每一项都具有相同逻辑地位。

## 4. A0—A10

### A0：预设终极意义缺席

框架采用：世界没有预设、对所有存在具有最终约束力的目的和评分标准。

这是哲学起点。它不能单独推出局部价值不存在，也不能推出行动被禁止。

### A1：虚无不变

对任一存在状态 \(x\in X\)：

\[
\operatorname{Bg}(x)=V
\]

存在或不存在不会把虚无背景变成另一种背景。

### A2：可能性展开

\(\Omega\) 容纳所有真正可能的实现方式。不同实现方式可以具有不同结构和权重。

可能性回答是否具有实现方式；概率回答不同结果的权重。两者不作为同一个术语使用。

### A3：可能性全实现

若状态 \(x\) 真正可能，则至少有一种实现方式实现它：

\[
\operatorname{Possible}(x)
\Rightarrow
\exists u\in\Omega:\operatorname{Realizes}(u,x)
\]

“真正可能”是原始谓词，目前没有完备判定程序。这是 A3 的主要开放问题之一。

### A4：分支集体包含

\[
C_i=\bigcup_{u\in\Omega}I_i(u)
\]

这个定义采用最大包含原则：全部与主体 \(i\) 对应的历时和分支实例都进入 \(C_i\)。谓词“与主体对应”的完整判据仍未定义。

### A5：分支共处

\(C_i\) 的成员可以被共同放入分支共处场中考察。最低强度的读法是体验与身份组织模型；把该场理解为独立外部本体，需要额外承担本体论承诺。

### A6：第一人称分支收敛

统一条件为：

\[
\operatorname{Possible}(D_t\mid h_t)
\land K(i,D_t,h_t)
\land \exists u\in W(h_t):R(i,D_t,u)=1
\]

在这些条件下，A6 规定：

\[
\exists u^\*\in W(h_t):
(h_t\rightsquigarrow_i u^\*)
\land R(i,D_t,u^\*)=1
\]

\(\rightsquigarrow_i\) 是 A6 引入的原始桥接关系，不代表已经说明了物理转移、意识筛选或叙事连续机制。没有 \(K\)，不能仅凭某个成功实现方式存在而推出当前第一人称经验完成。

### A7：目标更新

\[
(D_t,G_t)\longrightarrow(D_{t+1},G_{t+1})
\]

方向和具体目标可以随事实、能力与伦理判断更新。更新需要保留理由、失败条件和已经发生的后果；新目标不能追认旧目标已经完成。

### A8：未来自我确认

对指定主体、方向和实现方式：

\[
\operatorname{Completed}(i,D,u)=1
\iff R(i,D,u)=1
\]

这是一项反身完成判据。它需要额外约束，才能避免未来主体仅靠降低标准宣布完成。

### A9：观察者索引性

A6 以具体主体 \(i\) 及其历史 \(h_t\) 为索引。框架不要求一条特权实现方式同时满足所有观察者的互斥方向。

这个扩展不取消当前共同分支中的事实、他人主体性和明确同意。

### A10：局部因果与责任

在任一局部历史中：

\[
\operatorname{Action}_t+\operatorname{Conditions}_t
\longrightarrow
\operatorname{Consequences}_{t+1}
\]

身体、事实、法律、同意、资源和风险继续产生后果。其他编号不能抵消已经发生的损失或责任。

## 5. 五层自我的功能关系

| 编号 | 锚定名称 | 类型 | 功能 |
| --- | --- | --- | --- |
| S1 | 身体自我 | 主体载体 | 实现局部行动并承担因果 |
| S2 | 表象自我 | 体验呈现 | 呈现当前第一人称经验 |
| S3 | 分支集体自我 | 身份模型 | 包含历时和分支实例 |
| S4 | 虚无精神自我 | 实践／价值姿态 | 实例化“无所谓中的有所谓” |
| S5 | 虚无本身自我 | 本体背景 | 容纳存在与不存在 |

这不是生成链或五个同类集合。前三层描述主体尺度，第四层描述行动姿态，第五层描述背景。

可能性属于另一条概念轴，负责展开不同实现方式，不进入 S1—S5 的主体—背景分层。

## 6. 直接含义与未获推出的主张

接受相应编号后，可以直接重述：

1. A0 不能推出局部行动被禁止；
2. A4 把当前表象自我放入更大的身份集合；
3. A7 允许方向和目标诚实更新；
4. A6 在其三个条件成立时规定第一人称经验收敛；
5. A10 保留任何局部结果与责任。

下列主张没有由当前符号系统推出：

- 数学上的正概率自动生成真实分支；
- 想象一个目标即可证明它真正可能；
- A3 自动推出 A6；
- \(\rightsquigarrow_i\) 已具有可观察、可重复的机制；
- 未来自我确认能够抵消当前损失；
- 观察者索引性允许主体改写公共事实。
