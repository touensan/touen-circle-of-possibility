# B 版：《多恩可能性之圆》技术手册

> 公理、符号、反对意见与未决问题的阅读入口

这份手册面向想检验框架而不只使用框架的读者。若尚未读过核心论述，建议先读 [A 版大众导读](README.md)。

## 技术阅读的任务

B 版不重复讲一遍故事，而是回答四个问题：

1. 每项主张属于定义、推论还是独立公理？
2. 白话概念与符号怎样对应？
3. 哪些结论尚未获得足够论证？
4. 哪些使用边界不能由形而上主张取消？

## 核心符号速查

| 符号 | 锚定名称 | 白话作用 |
| --- | --- | --- |
| \(\Omega\) | 可能性总体 | 全部真正可能的实现方式 |
| \(u\) | 实现方式 | 一个分支或非时间实现方式 |
| \(h_t\) | 当前历史 | 时刻 \(t\) 之前已经发生的完整局部历史 |
| \(W(h_t)\) | 相容延续集合 | 与当前历史不冲突的后续实现方式 |
| \(C_i\) | 分支集体自我 | 与主体 \(i\) 对应的历时和分支实例集合 |
| \(D_t\) | 方向性吸引子 | 当前认可的大方向 |
| \(G_t\) | 具体目标 | 当前可表达和检验的目标形式 |
| \(K\) | 持续前进条件 | 行动、学习、反馈与修正持续指向方向 |
| \(R\) | 未来自我确认 | 未来主体是否确认方向已经实现 |
| \(V\) | 虚无背景 | 不因存在状态而变化的无差别背景 |
| \(\rightsquigarrow\) | 第一人称经验收敛关系 | A6 规定的经验归属关系；其机制仍未说明 |

完整条件见[符号化参考](FORMAL_SPEC.md)。

## 当前论证状态

| 问题 | 当前状态 |
| --- | --- |
| 没有终极意义是否禁止局部价值 | 可以给出逻辑区分：缺少命令不能推出行动禁令 |
| 一次失败是否定义完整主体 | 可以限制推论范围，但“完整主体”采用何种身份模型仍可争论 |
| 所有真正可能者是否都实现 | A3 规定如此；依据仍需独立辩护 |
| 当前第一人称为何归于目标分支 | A6 规定如此；机制与独立依据仍未解决 |
| 动态目标怎样避免移动标准 | 已有记录与退出条件，尚缺充分的同一性判据 |
| 多观察者如何共享稳定公共世界 | A9 提供索引性描述，完整机制仍未解决 |
| 框架能否产生经验上可区分的预测 | 尚未建立 |

“公理规定如此”只说明框架内部怎样运作，不构成对外部反对意见的驳回。

## 不适用的情境

以下情境不应把本框架当作主要判断工具：

1. 需要定量预测、可重复检测或专业责任结论的决策；
2. 使用框架正在削弱现实判断、放大冲动或鼓励不可逆风险的状态。

第一类应使用相应专业证据；第二类应暂停使用并寻求可信任的人或专业支持。
