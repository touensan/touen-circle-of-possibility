# 阅读与心理安全说明

《可能性之圆》讨论虚无、行动、自我与可能性。它是一套哲学框架，不是心理治疗、医学诊断或危机干预方案。

## 不要用危险行为“验证分支”

第一人称分支收敛是形而上公理，不是身体不会受伤、不会死亡或不会承担后果的科学保证。不要通过危险驾驶、停药、拒绝治疗、违法、伤害自己或他人来“测试”任何分支理论。

## 如果阅读让现实判断变差

如果这个框架让你明显更加焦虑、失眠、冲动、脱离现实，或开始无法区分比喻、哲学公理与当前事实，请先停止把它用于重大决定，并回到：

- 当前能共同验证的事实；
- 安全、低风险的下一步；
- 可信任的人；
- 合格的医疗或心理专业支持。

如果你正面临立即的人身危险或自伤风险，请优先联系当地急救服务、合格专业人员或身边能够立即陪伴和保护你的人。

## 哲学确定感不能替代专业判断

医疗、法律、财务、工程与公共安全问题，应依据相应专业证据、当地规则和具体风险评估。哲学信念可以组织方向，但不能替代诊断、合同、计算、检测和他人同意。

## 项目的最低护栏

> 方向可以坚定，方法必须可纠错；可能性可以无限，局部身体只有一个当前接口。
