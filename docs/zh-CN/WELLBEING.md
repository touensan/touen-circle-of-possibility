# 心理与现实护栏

《多恩可能性之圆》是哲学框架，不是心理治疗、医学诊断或危机干预方案。第一人称分支收敛公理（A6）也不是身体不会受伤、死亡或承担后果的保证。

## 不用危险行为验证框架

不要通过危险驾驶、停药、拒绝治疗、违法、伤害自己或他人、孤注一掷投资等行为“测试”分支或收敛。任何不可逆行为都先按当前证据和现实风险判断。

## 现实决策的七条规则

1. 形而上信念不充当概率预测；
2. 医疗、法律、财务、工程与公共安全事项交由相应证据和专业程序判断；
3. 优先低成本、可逆、能够产生反馈的小步行动；
4. 行动前写下失败、暂停和停止条件；
5. 保留可信任的反对声音，不用信念覆盖坏消息；
6. 他人的明确同意不能由任何假设分支替代；
7. 未实现目标不表示当事人不够真诚、不够努力或不配成功。

## 什么时候暂停使用

如果阅读或使用框架后出现以下情况，先停止将它用于重大决定：

- 明显加重焦虑、失眠或冲动；
- 难以区分比喻、哲学公理与当前事实；
- 开始忽视身体警告、财务损失或他人边界；
- 产生用高风险行为“证明自己一定会收敛”的想法；
- 工作、关系、安全或现实判断持续受损。

此时回到共同可验证的事实和安全、低风险的下一步，并联系可信任的人。若影响持续或加重，应寻求合格的医疗或心理专业支持。

如果正面临立即的人身危险或自伤风险，请优先联系当地急救服务、合格专业人员，或身边能够立即陪伴和保护自己的人。

## 最低原则

方向可以坚定，方法必须可纠错；任何总体设想都不能取消当前身体、事实、同意和后果。
