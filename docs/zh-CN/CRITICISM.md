# 未决问题与反对意见

> 本页记录框架目前最薄弱的部分，不以重复公理代替回答

阅读本页时，“框架当前选择”只表示内部怎样规定；它不构成对外部反对意见的驳回。每节分别给出反对意见、当前状态和仍需解决的问题。

## 先说明不适用场景

《可能性之圆》不适合作为以下情境的主要判断工具：

1. 需要定量预测、可重复检验或专业责任结论的决策；
2. 使用框架正在削弱现实判断、放大冲动或鼓励不可逆风险的状态。

前者应依据相应专业证据，后者应暂停使用并参阅[心理与现实护栏](WELLBEING.md)。

## 1. 可能性全实现公理依据什么

反对意见：

以下三条常见路线都不能推出“所有真正可能者都实现”：

| 路线 | 推理缺口 |
| --- | --- |
| 概率大于零 | 概率描述权重；它不自动制造分支，也不保证特定观察者经验到该结果 |
| 时间无限 | 时间不能取消系统规则、不可达状态和不变量 |
| 庞加莱回归 | 回归只适用于满足特定条件的动力系统；靠近旧状态不等于实现任意目标 |

具有有限测度并保持测度的系统，在适当条件下可能再次靠近初始状态。这个结论没有证明宇宙满足条件，也没有证明所有可想象状态、特定目标或第一人称经验都会实现。

框架当前选择：

可能性全实现公理（A3）直接规定：所有真正可能者都在可能性总体中具有至少一种实现方式。A3 不再借统计概率、无限时间、量子力学或回归定理作推导。

仍未解决：

- A3 除了作为公理，还有什么独立理由？
- “总体包含”为什么应被理解为实际实现，而不是可描述状态的目录？
- A3 是否产生任何可区分的经验后果？

## 2. 什么才算“真正可能”

反对意见：

如果框架允许可能性总体超出现有物理规律，却没有给出判定标准，它可能容纳任何主张，也就难以排除任何主张。

逻辑上可描述、当前物理可达、未来技术或许可达，以及纯粹能够想象，是四种不同强度的“可能”。把它们混在一起，会让 A3 失去明确适用范围。

框架当前选择：

框架明确拒绝“能够想象就算真正可能”，但目前没有完备判定程序。现实行动应优先采用可观察事实、物理限制、专业知识和可验证反馈。

仍未解决：

- 真正可能至少需要满足哪些必要条件？
- 超出现有物理知识与违反一切约束怎样区分？
- 判定标准改变时，过去对 A3 的使用是否需要撤回？

## 3. 总体包含为什么会变成第一人称经验

反对意见：

即使先接受 A3，也只能得到“目标实现方式存在”。它不能推出“当前第一人称经验会归于该实现方式”。

所有结局都在图书馆里，不表示手中的书会自动变成最想读的结局。同样，列出所有主体版本，并没有提供一个让当前经验优先归于目标版本的选择规则。

框架当前选择：

第一人称分支收敛公理（A6）直接规定：在方向仍真正可能、主体持续前进并存在未来自我确认的相容延续时，当前第一人称经验收敛于至少一个这样的延续。

这是独立桥接公理，不是 A3、行动循环或统计概率的推论。

仍未解决：

- 跨分支的“同一第一人称”依据身体、记忆、因果链还是其他关系？
- \(\rightsquigarrow\) 表示何种关系，为什么具有目标方向性？
- A6 如何避免幸存者偏差和只由成功者回顾确认？
- 什么观察会迫使框架修改或放弃 A6？

这是完整体系目前最核心的论证缺口。

## 4. 总体包含与经验时间怎样连接

反对意见：

框架同时使用未来、持续前进和非时间实现方式，容易让“最终”在两种含义之间滑动：

- 时间意义：先未完成，后来完成；
- 结构意义：完成状态始终被总体包含。

如果状态只是被非时间总体包含，尚未说明它为何成为当前主体之后会经历的状态。

框架当前区分：

| 锚定名称 | 含义 |
| --- | --- |
| 总体包含 | 某状态在可能性总体中具有实现方式 |
| 局部趋近 | 主体在经验时间中行动、反馈与修正 |
| 经验完成 | 未来自我确认方向已经实现 |

这套区分消除了用词混乱，却没有建立三者之间的机制。

仍未解决：

- 非时间实现方式如何与经验连续建立关系？
- “未来自我”在非时间结构中具体表示什么？
- 总体包含与局部失败之间是否存在可说明的连接规则？

## 5. 动态目标会不会使框架永远正确

反对意见：

如果失败后总能说“真正目标已经改变”，任何结果都可以被重新命名为成功。未来自我若拥有无限解释权，框架就可能失去失败条件。

框架当前约束：

目标更新（A7）要求保留方向性吸引子与具体目标的区别。实际使用时应预先记录：

1. 当前方向和具体目标；
2. 完成、失败、暂停与退出条件；
3. 可以调整和不可随意改写的部分；
4. 每次更新的事实依据；
5. 已经发生的损失和责任。

这些记录可以限制事后合理化，但不能完全解决“仍是同一方向”的身份问题。

仍未解决：

- 新旧方向保持连续的充分标准是什么？
- 未来自我确认如何避免单纯降低标准？
- 放弃不再值得的目标，应算合理退出还是另一种完成？

## 6. 多个观察者的目标冲突怎么办

反对意见：

两名主体可能追求互不相容的结果。把双方放入不同观察者相对分支，没有自动回答：分支中的失败者为何承担损失，公共事实如何稳定，以及他者是否仍被当作完整主体。

框架当前选择：

观察者索引性（A9）不要求一条特权分支同时满足所有目标。它只描述各观察者相对的收敛关系，不赋予任何人改写当前共同事实或控制他人的权利。

仍未解决：

- 不同观察者的相对分支如何同时定义而不循环？
- 多个第一人称怎样形成稳定的公共知识和制度？
- 当成功必然伴随他者损失时，框架依据什么伦理原则评价目标？

当前可确定的边界是：另一分支中的假设性同意，不能替代眼前当事人的明确同意。

## 7. 框架能否被经验区分

反对意见：

若成功由收敛解释，失败由“仍在途中”或“目标更新”解释，那么什么结果会与框架冲突？一个不能排除任何观察的体系，作为外部世界说明的可信度有限。

当前状态：

框架的行动部分可以分别研究，例如目标记录是否改善坚持和决策质量。但这类局部效果不能反过来确认 A3 或 A6。

A3、A6 与非时间实现方式目前没有明确的经验检验程序。它们可以作为哲学公理讨论，却不能因此获得经验理论的证据强度。

仍未解决：

- A6 能否提出与普通目标坚持不同的可观察预测？
- 哪些失败会被承认为公理的反例，而不是使用条件未满足？
- 外部本体论若长期不可区分，应保留到什么强度？

## 8. 第一人称收敛会不会造成现实危险

反对意见：

“最终会实现”可能压过风险警告，诱发不可逆投入、延误治疗、忽视统计、侵犯他人边界，或在失败时责怪当事人不够努力。

一个框架的风险不仅取决于作者原意，也取决于它最容易被怎样误用。

当前边界：

- 方向确信不等于当前方案正确；
- 形而上公理不充当概率预测；
- 高风险问题依据专业证据和程序；
- 优先可逆的小步试验，并预先写下停止条件；
- 不用未来成功抵消当前损失；
- 不把失败道德化。

完整规范集中在[心理与现实护栏](WELLBEING.md)，不再由每份文档重复展开。

仍未解决：

- 方向上的“必然”是否仍会在心理上压过止损信号？
- 如何系统记录负面使用结果，而不只展示成功经验？
- 哪些心理状态需要更明确地暂停使用框架？

| 无终极意义不禁止局部价值 | 可论证的逻辑区分 |
