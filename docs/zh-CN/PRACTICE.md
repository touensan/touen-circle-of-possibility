# 五层行动版

> 把《多恩可能性之圆》变成一张可填写的行动卡

这一版本只使用五层自我进行检查，再用行动—反馈—修正循环推进目标。它不要求接受可能性全实现公理或第一人称分支收敛公理。

## 五层不是五个步骤

五层是同时观察同一件事的五个角度：

| 层次 | 行动前要问的问题 |
| --- | --- |
| 身体自我 | 当前身体、时间、金钱、能力与安全条件怎样？下一步能否真实执行？ |
| 表象自我 | 此刻知道什么、感受什么？哪些是事实，哪些是情绪或猜测？ |
| 分支集体自我 | 从长期和多条可能路线看，还有哪些选择？今天的结果会怎样影响未来版本？ |
| 虚无精神自我 | 没有终极标准时，仍选择认真对待什么？为什么愿意行动？ |
| 虚无本身自我 | 能否不把一次成败升级为对整个存在的最终判决？ |

第五层只提供背景视角，不替任何具体方案作决定。

## 行动—反馈—修正循环

### 1. 写方向

方向性吸引子 \(D_t\) 是希望长期靠近的大方向，例如“提高行动自由”或“持续创造可靠作品”。

它可以坚定，但不能覆盖新事实。

### 2. 写具体目标

具体目标 \(G_t\) 必须能够判断是否完成。至少写清：

- 预期结果；
- 时间范围；
- 当前成功标准；
- 明确的失败、暂停或退出条件。

### 3. 核对现实

分别列出：

- 已确认事实；
- 尚未确认的假设；
- 可用资源；
- 主要风险；
- 可能受影响的人及其边界；
- 需要专业判断的事项。

可能性不等于愿望。缺少证据时，应标为“不知道”，而不是自动标为“可行”。

### 4. 选择最小可检验行动

优先选择成本可控、尽量可逆、能够产生新反馈的一步。一次行动只需要回答一个具体问题，例如：

- 这种方法是否有人愿意使用？
- 当前技能是否达到最低要求？
- 这项合作能否获得明确同意？
- 这个方案的实际成本是多少？

### 5. 记录反馈并决定

行动后先记录结果，再解释结果。决策只有四类：

| 决策 | 适用情况 |
| --- | --- |
| 继续 | 证据支持当前路线，风险仍可接受 |
| 修正 | 方向仍认可，但方法或具体目标需要改变 |
| 暂停 | 证据、资源、身体状态或外部条件暂时不足 |
| 结束 | 目标已不值得、不再可能、代价不可接受或侵犯必要边界 |

结束具体目标不等于整个人生失败。继续也不等于重复无效做法。

## 使用边界

- 不用第一人称分支收敛替代风险估计；
- 不用“未来会成功”覆盖当前损失；
- 不用任何可能分支替代他人的明确同意；
- 医疗、法律、财务、工程与公共安全问题仍交由相应证据和专业程序判断；
- 如果使用框架导致冲动、失眠、脱离现实或危险行为，停止将它用于重大决定，并参阅[心理与现实护栏](WELLBEING.md)。
