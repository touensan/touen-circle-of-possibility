# A 版：读懂《多恩可能性之圆》

> 一篇可以独立读完的读者导读

《多恩可能性之圆》试图回答：如果世界没有预设的终极意义，一次失败意味着什么，完整的自我包括什么，人又该怎样继续行动？

本文按五个核心命题展开。每个术语第一次出现时建立白话映射，之后只使用固定名称。需要检验公理、符号和反对意见时，再进入 [B 版技术手册](TECHNICAL.md)。

## 0. 阅读契约：先分清话的类型

本文使用六种标签：

| 标签 | 它在回答什么 |
| --- | --- |
| 定义 | 一个词在本框架中具体指什么 |
| 逻辑判断 | 已给前提能够推出什么、不能推出什么 |
| 体验模型 | 一个人可以怎样组织和理解自身经验 |
| 实践方法 | 怎样把思想变成可检查的行动 |
| 哲学公理 | 框架主动选择、但不由前文证明的起点 |
| 现实边界 | 哪些事实、责任和风险不能被框架取消 |

“哲学公理”不是隐藏的逻辑结论。读者可以拒绝某项公理，同时继续使用不依赖它的部分。

五个命题及其主要类型如下：

| 编号 | 锚定名称 | 主要类型 |
| --- | --- | --- |
| 1 | 虚无与局部价值 | 哲学公理＋本体论公理＋逻辑判断 |
| 2 | 失败的局部性 | 逻辑判断 |
| 3 | 当前自我与分支集体自我 | 体验模型＋身份公理与集合定义 |
| 4 | 行动与反馈循环 | 实践方法 |
| 5 | 第一人称分支收敛公理 | 独立形而上公理 |

## 1. 虚无与局部价值

类型：哲学公理＋本体论公理＋逻辑判断

### 核心定义

框架采用“世界没有预设的终极意义”作为起点。这里的终极意义，指世界提前为所有主体规定的最终目的和评分标准。

白纸比喻只在这里使用一次：纸上没有预印的唯一正确图案，对应“预设终极意义缺席”（A0）；纸面出现图案或保持空白，都不会产生一份宇宙级评分表，对应“虚无不变”（A1）。框架中的虚无背景，指的正是不因存在或不存在而改变的无差别背景。

### 能够推出什么

“没有预设答案”和“任何行动都被禁止”是两句话。前者不能推出后者。

爱、创造、休息、合作或追求目标，可以在身体需要、个人选择和现实关系中形成局部价值。它们不需要先成为宇宙级答案，才能在当前生活中成立。

### 不能推出什么

没有终极裁判，不等于没有他人、规则和后果。伤害、同意、承诺与法律仍属于共同生活中的真实约束。

### 框架的选择

“预设终极意义缺席”是哲学起点，“虚无不变”是本体论公理。读者可以检验它们是否清楚、自洽、是否有实践价值，但不能把它们误认成由下一节事实推导出的结论。

## 2. 失败的局部性

类型：逻辑判断

### 核心定义

失败是某个结果相对于某项目标或标准没有达成。考试未过、项目亏损或关系结束，都可能带来真实损失，也可能暴露能力、方法、资源或判断上的问题。

### 论证边界

一次结果能够证明的范围，取决于实际观察到的事实。它可以支持“这次没有达到标准”，却不能单独支持“这个主体在所有时间、所有目标和所有可能发展中都已经失败”。

这不是鼓励忽略坏结果，而是限制结论的强度：局部证据只能承担局部结论。

### 操作含义

面对失败时，依次记录：

1. 实际发生了什么；
2. 造成了哪些损失，谁受到影响；
3. 哪些原因已有证据，哪些只是猜测；
4. 哪些条件可以改变；
5. 当前目标应继续、修正、暂停还是结束。

这一命题不要求接受可能分支或第一人称分支收敛。

## 3. 当前自我与分支集体自我

类型：体验模型＋身份公理与集合定义

### 先定义“实现方式”和“分支”

可能性总体中的成员统称为“实现方式”。具有时间或因果延续结构的实现方式，才称为“分支”；不按经验时间先后描述的成员，称为“非时间实现方式”。

河流分叉可以帮助理解分支怎样从共同上游展开不同后续，但比喻到此为止。分支不默认等于量子分支、物理平行宇宙，也不表示人可以在现实中任意切换世界。

### 五层自我

五层不是五个灵魂，也不是五个同类型实体：

| 编号 | 锚定名称 | 作用与关系 | 一句话例子 |
| --- | --- | --- | --- |
| 1 | 身体自我 | 行动载体；实现行动 | 双手按下键盘，身体承担时间与疲劳成本 |
| 2 | 表象自我 | 当前体验；呈现经验 | 此刻感觉到“是我在写这段文字” |
| 3 | 分支集体自我 | 历时与分支实例集合；包含实例 | 包括曾经学习、此刻写作及未来可能继续写作的主体实例 |
| 4 | 虚无精神自我 | 行动模式；实例化态度 | 没有终极标准，仍选择把这段文字写清楚 |
| 5 | 虚无本身自我 | 无差别背景；容纳一切 | 写成或写坏，都不会产生宇宙级终审判决 |

白话中的“当前截图”只对应表象自我的局部呈现；“更完整的自我”是分支集体自我的解释性说法。两者不是新术语。

第五层是背景层，不是行动步骤。它之所以保留，是为了表达主体最终被放入怎样的无差别背景，而不是为了直接参与每一次决策。

### 三个容易混淆的概念

| 锚定名称 | 包含什么 |
| --- | --- |
| 可能性总体 | 所有真正可能的实现方式 |
| 分支集体自我 | 与某一主体相对应的历时和分支实例 |
| 分支共处场 | 把这些主体实例共同放置其中的抽象结构 |

“可能性之圆”是可能性总体的公开名称和整体意象；它不等于分支共处场。

### 框架的选择

把当前自我看成长期过程，可以只作为体验模型使用。把所有可能分支实例都视为同一分支集体自我的成员，则是更强的身份公理。跨分支身份究竟依据身体、记忆、因果还是其他关系，目前仍是开放问题。

## 4. 行动与反馈循环

类型：实践方法

### 核心定义

框架区分“方向性吸引子”和“具体目标”：

- 方向性吸引子：主体持续认可、愿意靠近的大方向，记作 \(D_t\)；
- 具体目标：当前能够表达和检验的完成状态，记作 \(G_t\)。

指南针可以帮助理解方向性吸引子：它指出方向，不承诺眼前道路正确，也不规定只能走一条路线。

### 行动循环

`确定方向 → 写出具体目标 → 采取行动 → 观察反馈 → 修正方法或目标`

信念本身不能完成局部因果链。身体行动、知识、合作、工具和资源，才会改变下一步条件。

### 可能性与概率

- 可能性回答某个状态是否真正可实现；
- 概率回答不同可能结果的权重或出现机会。

能想象一个结果，不能证明它真正可能；一个结果真正可能，也不能说明当前方案的成功概率很高。现实决策仍需依据相应证据估计风险。

### 动态目标与未来自我确认

具体目标和方向都可以随新事实、能力与伦理判断更新。更新必须记录理由，不能在失败后偷偷降低标准，再把旧目标追认为已经完成。

“未来自我确认”是完成标准：由认知更充分的未来主体确认方向已经实现。它为目标更新提供弹性，也带来事后合理化风险，因此需要预先记录目标、失败条件和更新依据。

## 5. 第一人称分支收敛公理

类型：独立形而上公理

这是完整体系最强的主张，也是整条论证中不能隐藏的跳跃。

### 公理之前已经有什么

在进入第一人称分支收敛前，框架已经提出三件事：

1. 当前表象自我不是完整主体；
2. 若接受可能性全实现公理，一个真正可能的目标状态会在可能性总体中得到某种实现；
3. 行动、反馈和修正能够改变局部条件及实现概率。

由这些前提，最多可以得到：“目标实现版本被总体包含，并且行动可能改善当前条件。”

### 仍然缺少哪一步

“某个实现版本存在”不能自动推出“当前第一人称会经验到该版本”。两者之间还缺少身份连续与经验归属规则。

这个缺口不能靠“所有分支都存在”、无限时间或统计概率补上。框架选择用一项独立公理补上它，而不是把它伪装成推论。

### 公理的完整表述

如果方向 \(D_t\) 从当前历史出发仍真正可能，主体持续把行动与修正指向它，并且存在由未来自我确认实现的相容延续，那么当前第一人称经验收敛于至少一个这样的延续。

锚定名称是“第一人称分支收敛公理”，形式化编号是 A6。首次锚定后可简称“第一人称收敛”。旧文中的“核心押注”“最终抵达”和“最大胆的主张”都只是在描述 A6，后续文档不再把它们当作并列术语。

### 读者应怎样对待它

- 把它当作哲学公理：检验它与其他公理是否相容，并继续追问依据；
- 把它当作实践承诺：观察它是否帮助持续行动，同时保留止损和纠错；
- 拒绝它：继续使用前四个命题，不声称接受完整体系。

这三种态度应明确区分。A6 目前不是第一人称连续性的解释机制；“为什么当前经验必然归于目标分支”仍是未决问题。

### “总体包含”与“最终”

非时间视角只是补充解释，不承担证明 A6 的任务：

| 锚定名称 | 含义 |
| --- | --- |
| 总体包含 | 目标状态在可能性总体中具有实现位置 |
| 局部趋近 | 主体在经验时间中行动、反馈与修正 |
| 经验完成 | 未来自我确认方向已经实现 |

三个概念相互关联，但不能互相替代。总体包含尤其不能单独推出当前第一人称的经验完成。

### 多个观察者

完整体系还采用观察者相对分支：互斥目标不必在同一条特权分支中同时满足。但这个设定不能替代当前共同现实中的事实、协商和同意，也没有完全解决不同观察者如何共享稳定公共世界的问题。

## 6. 把框架用于今天

不接受 A6，也可以使用以下流程：

1. 写下方向性吸引子：真正想长期靠近什么；
2. 写下具体目标：怎样算完成，怎样算失败；
3. 核对现实：证据、风险、资源、他人边界与专业要求；
4. 选择最小、可逆、可观察的下一步；
5. 记录结果，不用信念覆盖坏消息；
6. 根据反馈继续、修正、暂停或结束，并承担已经发生的后果。

可直接使用的模板见[五层行动版](PRACTICE.md)。

## 7. 当前未决问题

完整体系至少仍需回答：

1. 什么构成跨分支主体的身份对应？
2. “真正可能”如何与纯语言想象区分？
3. 为什么第一人称连续性遵循 A6？
4. 动态目标如何避免事后移动标准？
5. 多个观察者的相对分支如何形成稳定公共世界？

这些问题不是已经被“框架有意如此”解决的异议。它们决定 A6 和相关本体论能够获得多强的可信度。

## 8. 理解自测与下一步

暂时不看术语表，试着用自己的话回答：

1. 为什么没有预设的终极意义，不等于人不能选择局部价值？
2. 一次失败能够证明什么，又不能证明什么？
3. 五个核心命题与五层自我分别解决什么问题？
4. 从“目标实现版本存在”到“当前第一人称会亲身经验它”，中间缺少哪一步？

如果答案只能重复一句口号，还没有真正理解对应命题。可以回到相关章节，先解释关系，再记术语。
