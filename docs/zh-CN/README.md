# 《多恩可能性之圆》A 版大众导读：先说人话，再谈术语

《多恩可能性之圆》想处理四个常见困境：人生似乎没有统一答案、一次失败让人否定自己、眼前状态像是永远不会改变，以及想前进却不知道下一步做什么。

这篇导读先用日常中文讲清思路。严谨定义、符号和反对意见统一放在 [B 版技术手册](TECHNICAL.md)。

## 0. 开始之前：可以只读前四节

第 1—4 节是基础框架。它们分别讨论意义、失败、自我和行动，彼此能够独立使用。

第 5 节是完整体系额外加入的可选假设。它不是前四节自然推出的结论。不认同它，可以直接跳到第 6 节。

本文使用三种简单提示：

- **基础观点：** 帮助重新理解一个问题；
- **行动方法：** 可以在现实中尝试并检查结果；
- **可选假设：** 框架主动相信，但目前没有从前文证明。

B 版会进一步区分定义、逻辑判断、体验模型、实践方法、哲学公理和现实边界。第一次阅读不需要先记这些分类。

## 1. 人生没有标准答案，价值仍可以自己创造

**先说人话：** 人生没有一份天生写好的统一答案。人仍然可以选择认真对待家人、健康、工作、创作或一顿好饭。

想象一张没有预印图案的白纸。纸上没有“唯一正确画法”，不代表不能落笔。画什么、为什么画，需要由画的人和真实生活共同决定。

这个框架把“世界没有预写的最终目的和评分标准”作为起点。技术文档称它为“预设终极意义缺席”。框架还选择相信：无论画面出现还是消失，那张没有最终评分表的背景都不会改变。

这只能说明没有宇宙级裁判，不能取消现实中的他人、承诺、法律和后果。一个选择是否值得，仍要看身体需要、个人承诺、共同生活与实际影响。

既然没有一张给整个人生打分的总表，下一步就要问：一次失败究竟有资格说明多少？

## 2. 一次失败，只能证明这一次发生了什么

**先说人话：** 求职被拒，说明这次没有拿到岗位；考试没过，说明这次分数没有达到标准。它们都可能很痛，也都需要复盘，但不能直接证明“我整个人不行”。

失败是某个结果没有达到某个目标。结论能说多大，取决于证据有多大。一次结果可以暴露准备不足、方法错误、资源不够或判断失误，却无法独自概括一个人在所有时间、所有事情上的价值和能力。

这不是逃避责任。面对失败，至少要写清五件事：

1. 实际发生了什么？
2. 造成了哪些损失，影响了谁？
3. 哪些原因已有证据，哪些只是猜测？
4. 哪些条件还可以改变？
5. 这件事应该继续、修改、暂停还是结束？

把结论限制在证据能够支持的范围内，就是“失败的局部性”。

一次结果之所以不能概括整个人，也因为眼前的自己只是一个时间截面。接下来要把“我”放回更长的人生里看。

## 3. 今天的自己，是人生的一张截图

**先说人话：** 此刻的感受和处境都是真的，但它们不是整部人生。过去形成的经验、现在能够行动的身体，以及未来仍可能变化的部分，共同构成更完整的自己。

这里的“可能路线”，指从当前条件出发仍可能出现的后续。它不默认是量子世界或真实存在的平行宇宙，也不表示人可以随意切换现实。

技术文档把跨越过去、现在和可能未来的主体整体叫作“分支集体自我”。名字很长，第一次阅读只需记住一句话：**不要只用今天这一帧，定义整部人生。**

### 五层自我：五个观察角度

五层不是五个人格，也不是五个行动步骤：

1. **能行动的我（身体自我）：** 身体执行动作，也承担疲劳、时间、金钱和风险。
2. **正在体验的我（表象自我）：** 此刻的感受、记忆和自我评价。
3. **跨越时间与可能路线的我（分支集体自我）：** 把过去、现在和未来可能成为的自己放在一起看。
4. **仍然选择在乎的我（虚无精神自我）：** 世界没有统一答案，仍决定认真对待一些事。
5. **承载一切的背景（虚无本身自我）：** 像一座舞台。戏可以演好，也可以演坏，舞台本身不为任何一场戏作最终判决。

前两层最贴近日常经验；第三层是一种更长时间尺度的自我模型；第四层描述行动态度；第五层只是背景。它们不是五个同类型实体。

五个核心命题是理解问题的顺序，五层自我是观察主体的角度。前者回答“怎样看待意义、失败和行动”，后者回答“从哪些尺度理解自己”。不需要把两套结构硬配成五组。

当眼前状态不再被当成最终定论，下一步就不是空想所有未来，而是用行动去确认哪条路真的走得通。

## 4. 方向决定往哪走，反馈决定怎样走

**行动方法：** 确定方向 → 写出具体目标 → 采取一小步行动 → 观察反馈 → 调整方法或目标。

框架区分两件事：

- **大方向：** 长期愿意靠近的状态，例如“拥有更稳定的生活”或“持续做可靠的作品”。技术名称是“方向性吸引子”。
- **具体目标：** 当前能够判断是否完成的结果，例如“三个月内完成一份作品集”。

方向可以稳定，路线必须接受事实检查。相信自己值得找到工作，不能证明眼前这份简历有效；想让身体康复，也不能替代检查、治疗和休息。

“可能”只回答一条路是否走得通，“概率”回答它目前有多大机会走通。能想象不代表真的可能；真的可能也不代表现在的成功率很高。

因此，每次行动最好小到能够承担、清楚到能够观察。例如，不先决定“我能不能成为作家”，而是先写 500 字，请一位目标读者复述重点。反馈用来修改下一步，不用来给整个人下判决。

到这里，基础框架已经完整。下一节会加入一个更强的信念，它不是行动循环成立的必要条件。

## 5. 完整体系额外相信什么

> **可选假设：不认同这一节，不影响使用前四节。**

完整体系选择相信：如果一个方向仍有实现可能，人也持续行动、学习和修正，那么亲身经历的人生最终会到达一个由未来自己确认“已经做到”的结果。

技术文档把这个信念称为“第一人称分支收敛公理”，编号为 A6。白话理解是：**只要路还在，也没有停止校正，未来的自己终会确认这段努力抵达了方向。**

### 为什么它不是前四节的结论

即使某个成功版本“有可能存在”，也不能自动证明眼前这个人一定会亲身经历它。中间还缺一条规则：为什么当前经验会延续到那条路线，而不是别的路线？

框架用 A6 直接补上这个缺口，并诚实地把它标成公理。目前它仍缺少独立机制和充分论证，因此读者可以：

- 接受它，把它当作完整体系的哲学信念；
- 暂时搁置，只观察它有没有实践价值；
- 拒绝它，继续使用意义、失败、自我和行动四个基础观点。

这三种选择都不该混在一起。详细论证和反对意见见 [B 版技术手册](TECHNICAL.md)。

## 6. 今天就能使用的 5 分钟方法

拿一件正在困扰自己的事，完成下面六步：

1. 写下真正想靠近的大方向；
2. 写下本轮可以检查的具体目标；
3. 分开记录事实、情绪和未经证实的猜测；
4. 核对身体、时间、金钱、风险和他人边界；
5. 选择一个成本可控、尽量可逆、能够带来反馈的小行动；
6. 根据结果决定继续、修改、暂停或结束。

例如，求职被拒后，可以先询问反馈、修改一版简历，再投递两个匹配岗位。新结果回答的是“这次方法是否更有效”，不是“我这个人是否值得”。

可复制的记录模板和完整例子见[《5 分钟行动卡》](PRACTICE.md)。

## 7. 现实边界和仍未解决的问题

> ⚠️ 这个框架帮助整理心态和行动，不替代现实判断。

医疗问题仍需专业诊断，法律问题仍要查规则与合同，合作仍需眼前当事人的明确同意。任何“未来会成功”的信念，都不能抹掉当前损失或替别人承担后果。

完整体系仍有几个公开问题：

1. 怎样判断一条路线是真的可能，而不只是能够想象？
2. 跨越不同可能路线时，什么让一个人仍是“同一个人”？
3. 为什么当前经验一定遵循 A6？
4. 目标改变时，怎样避免事后降低标准？
5. 不同人的目标冲突时，怎样解释共同现实？

这些问题不是一句“框架就是这样规定的”就能解决。它们集中记录在[未决问题与反对意见](CRITICISM.md)。

## 8. 理解自测与下一步

暂时不看术语表，试着用自己的话回答：

1. 人生没有统一答案，为什么仍然可以认真在乎一些事？
2. 一次失败能够证明什么，又不能证明什么？
3. 五个核心命题和五层自我分别用来做什么？
4. 为什么第 5 节只能算可选假设，不能算前四节的结论？
