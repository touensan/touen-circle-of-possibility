# Security and private disclosure

This repository contains public philosophical writing only. Private source
archives, personal data, credentials, and identifiable third-party material
must never be committed.

Do not report a privacy or security problem by pasting sensitive evidence into
a public Issue, Discussion, Pull Request, or comment.

Use the repository's **Security → Report a vulnerability** channel when it is
available. Include only the minimum information needed to locate and remove the
problem.

Public, non-sensitive documentation errors can be reported through the normal
Issue templates.

See [PRIVACY.md](PRIVACY.md) for the clean-room policy and response process.
